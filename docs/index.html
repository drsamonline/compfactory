compfactory

The development workspace for CHCE — the Chimera Hybrid Compression Engine. Not a product: the place where four repositories are held to one architecture and one set of rules, so that each can stay single-purpose.

The four repositories

RepositoryWhat it is
heavenzip The orchestrator — chains prebuilt binaries into one package
ziptastic The native engine — one binary, no runtime dependencies
HCS The vendored source vault every compressor is built from
compfactoryThis workspace — the rules and the phase gates

The rules it enforces

One purpose per repoIf a file does not belong in a repository, it does not go there — not even temporarily.
Phases in orderEach repo has an agent prompt listing phases. A phase's exit tests must pass before the next one starts.
Failures are committedA phase that fails its gate is committed as failed, with the reason — so the history shows what was tried, not only what worked.

The workspace is public because the architecture is worth reading, not because there is anything to install.
